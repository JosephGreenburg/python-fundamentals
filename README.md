# Python Fundamentals

Deliberate practice repository for rebuilding core Python skills from the ground up.

## Purpose

This repository exists to rebuild a strong foundation in Python through intentional, structured practice. 

The goal is not just to make code work, but to understand **what each line does** and **how it relates to the surrounding code**.

## Learning Philosophy

- Prefer clarity over cleverness
- Understand before abstracting
- Build small, focused examples
- Progress from simple to complex
- Revisit concepts until they feel natural
